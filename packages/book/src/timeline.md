# Timeline

| Date | Moment |
| --- | --- |
| December 2013 | Yann, Pierre and Cédric meet at the Alpha Mercure hotel bar in Luxembourg and decide to organize their own event |
| January 2014 | Christian Jolas designs the #play14 logo |
| March 14th, 2014 | First #play14 in Esch/Belval, Luxembourg: 34 players, hosted at the Technoport thanks to Diego De Biasio |
| March 27th, 2015 | Second Luxembourg edition; meeting Chris Caswell and Christina Ohanian |
| September 11th, 2015 | London: first event outside Luxembourg |
| November 20th, 2015 | Beirut: first event in the Middle East, hosted by Pierre Hervouet |
| 2016 | Milano and Hamburg join |
| 2017 | Madrid, Berlin, Timisoara, Barcelona and Amsterdam join; eight events |
| 2018 | Basel, Porto and Bari join; eleven events; mentoring becomes a rule around 2018–2019 |
| March 2019 | Sydney: first event in Oceania, hosted by Hanna Karlsson |
| May 31st, 2019 | Mexico: first event in the Americas, hosted by Ulises Aguila |
| October 25th, 2019 | Kuala Lumpur: first event in Asia, hosted by Fred Ducros; 14 events that year |
| February 2020 | Luxembourg 2020 canceled because of COVID-19 |
| May 9th, 2020 | First online #play14, run by the Stuttgart team |
| July 25th, 2020 | The big one: a 24-hour event following the sun, with 18 hosts; 15 events canceled that year |
| November 11th, 2021 | Utrecht: first event after COVID |
| 2022 | Seven events; back to (almost) normal |
| 2023 | Nine events; first Asian event after the pandemic in Manila; Zagreb, Curia and Zürich join |
| March 21st, 2024 | 10th anniversary at the Technoport in Esch/Belval, kids welcome for the first time |
| April 19th, 2024 | Bangalore: first event in India |
| October 25th, 2024 | Singapore: first edition; 14 events in 2024, matching 2019 |
| 2025 | Eleven events; Pune, Bangkok, Aveiro, Vinkeveen and Nancy (first in France) join |
| 2026 | Delhi and Mumbai join; India now counts four cities |
| March 14th, 2026 | Twelve years on: *#play14 in 14 words* at GamiCon 38 |
| October 2026 | 93 events held in 40 cities across 20 countries |
